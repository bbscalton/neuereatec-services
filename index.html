The headline · OTP / SMS Verify API

Verify a phone number in two API calls.

Your app asks us to send a code. We text it from our GSM gateway. The user types it in, you ask us to check it. Sign-up confirmation, passwordless login and two-step checks, without running your own SMS stack.

your-server — terminal
# 1. Send a code
curl -X POST https://api.example.com/api/v1/otp/send \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"to":"+15551234567","app_name":"MyApp"}'
→ {"id":"otp_8f2c1a","status":"sent","expires_in":300}
 
# 2. Check what the user typed
curl -X POST https://api.example.com/api/v1/otp/verify \
  -d '{"to":"+15551234567","code":"482913"}'
→ {"valid":true,"status":"approved"}

GSM SIM bridge

A regular phone number that reaches any extension.

Our GSM gateway puts local mobile lines inside your business phone system. Customers dial an ordinary mobile number; the call rings the extension, ring group or menu you choose. Staff call out on the same number.

  • Inbound mobile calls to any extension or IVR
  • Outbound calls from desk phones and the SIPDesk softphone
  • Send and receive SMS from your PBX or apps
  • Also powers the OTP Verify API

Developers

Quick start

Base URL https://api.example.com/api/v1 (placeholder). JSON in, JSON out. Authenticate with Authorization: Bearer YOUR_API_KEY and keep the key on your server.

curl -X POST https://api.example.com/api/v1/signup \
  -H "Content-Type: application/json" \
  -d '{"name":"Jane Dev","email":"jane@example.org","company":"Example Ltd","use_case":"Login codes"}'
→ {"status":"pending","message":"An admin will review your request."}
# Once approved, your API key is emailed to you.
curl -X POST https://api.example.com/api/v1/otp/send \
  -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"to":"+15551234567","app_name":"MyApp"}'
→ {"id":"otp_8f2c1a","to":"+15551234567","status":"sent","expires_in":300}
curl -X POST https://api.example.com/api/v1/otp/verify \
  -H "Authorization: Bearer YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"to":"+15551234567","code":"482913"}'
→ {"to":"+15551234567","valid":true,"status":"approved"}
→ {"to":"+15551234567","valid":false,"status":"invalid","attempts_remaining":2}
curl -X POST https://api.example.com/api/v1/sms \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"to":"+15551234567","message":"Hello","ref":"appt-42"}'
→ {"id":"sms_31d9e0","status":"queued","ref":"appt-42"}

curl https://api.example.com/api/v1/sms/sms_31d9e0 -H "Authorization: Bearer YOUR_API_KEY"
→ {"id":"sms_31d9e0","status":"delivered"}  # queued | sent | delivered | failed
curl https://api.example.com/api/v1/usage -H "Authorization: Bearer YOUR_API_KEY"
→ {"period":"2026-10","otp_sent":1240,"otp_verified":1102,"sms_sent":310}
