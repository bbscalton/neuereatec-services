Local VLAN speed test — why it misleads

Local VLAN test shows LAN speed, not bonded speed. To measure real bonding, the test server must be beyond the links.
✗ Misleading

Test server on local VLAN 20

~940 Mbps

≈ 1 Gbps — this is the switch speed. Phone (VLAN 10) → Test Server (VLAN 20) never leaves the building, so the five links aren't measured at all.

Real internet speed: ~40–80 Mbps

The 940 is switch speed only. Your actual internet speed is limited by the single return link.

✓ Real

Same setup, test server beyond the dishes (Hetzner)

~250 Mbps down

Raw sum of links: ~380 Mbps (80+90+70+100+40)
Realistic bonded: 230–300 Mbps (60–80%)
Traffic actually crosses the Starlinks and the cellular modem.
